# Winifred Daniels Dzeagu — Portfolio Website

A responsive static portfolio website built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For best local development, serve the folder with VS Code Live Server or another static web server.

## Included
- Responsive hero and bold editorial portrait treatment (no decorative halo or rings)
- Portrait slideshow using included image assets
- About, featured project, gallery, credentials, tech stack, and contact sections
- Sticky navigation, scroll reveals, and page-curtain anchor transitions
- Reduced-motion accessibility support
- Contact form that prepares an email in the visitor's default mail app

## Before publishing
- Confirm all professional experience, technology skills, project descriptions, and profile links.
- Add verified project links and a downloadable CV if available.
- The contact form is a static-site mailto handoff, not a server-side form submission. If you want messages delivered without opening the visitor's email app, connect a form service or backend.
- Google Fonts are loaded from the internet; system fallback fonts are provided.

## Deploy
Upload the contents of this folder to a static hosting service such as Netlify, Vercel static hosting, or GitHub Pages. Keep the `assets` folder alongside `index.html`.
